## Descripción del Proyecto
*The School of Oblivion* es un entorno interactivo desarrollado en Unity que combina mecánicas de exploración y lógica de puzzles. Este proyecto sirve como portafolio técnico para demostrar la implementación de sistemas modulares en C# y la optimización de entornos 3D.

## Características Técnicas Implementadas
- **Sistema de Interacción:** Lógica personalizada para la recolección de objetos (llaves) y activación de eventos mediante Raycast.
- **Arquitectura de Código:*

* Uso de programación orientada a objetos (POO) para la gestión de estados de enemigos y sistemas de vida.
- **Iluminación y Atmósfera:** Configuración de Skyboxes HDR (Cold Sunset) y optimización de materiales para entornos inmersivos.
- **Gestión de Assets:** Integración de modelos complejos desde Blender y texturizado de alta resolución (4K).
